🚀 DEPLOYMENT OPTIONS

Option A: PM2 (Recommended for cPanel)
────────────────────────────────────
  1. npm install -g pm2
  2. bash quick-deploy.sh
  3. pm2 save
  4. pm2 startup

  Benefits: Simple, auto-restart, process management
  Command:  pm2 monit

Option B: Docker (Most reliable)
────────────────────────────────
  1. docker-compose -f docker-compose.prod.yml build
  2. docker-compose -f docker-compose.prod.yml up -d
  3. docker ps

  Benefits: Isolated environment, easy scaling
  Command:  docker-compose logs -f

Option C: Systemd Service (Full control)
─────────────────────────────────────────
  1. sudo cp glovia-backend.service /etc/systemd/system/
  2. sudo systemctl enable glovia-backend
  3. sudo systemctl start glovia-backend
  4. sudo systemctl status glovia-backend

  Benefits: OS-level integration, automatic restarts
  Command:  sudo journalctl -u glovia-backend -f

🆘 TROUBLESHOOTING

Problem: Application won't start
  $ pm2 logs glovia-backend
  $ npm run build
  $ bash quick-deploy.sh

Problem: High memory usage
  $ pm2 kill
  $ pm2 start dist/main.js --max-memory-restart 300M

Problem: Slow responses
  $ curl http://localhost:3001/health
  $ pm2 monit
  $ Check database connection

Problem: Database connection failed
  $ echo $DATABASE_URL
  $ mongosh --connection-string=$DATABASE_URL
