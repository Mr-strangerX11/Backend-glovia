🚀 HOW TO DEPLOY (3 OPTIONS)

OPTION 1: PM2 (Fastest - Recommended for cPanel)
──────────────────────────────────────────────────
1. npm ci --only=production
2. npm run build
3. bash quick-deploy.sh
4. Done! ✅

Time required: 5 minutes
Best for: cPanel, shared hosting

OPTION 2: Docker (Most Reliable)
─────────────────────────────────
1. docker-compose -f docker-compose.prod.yml build
2. docker-compose -f docker-compose.prod.yml up -d
3. Done! ✅

Time required: 10 minutes
Best for: VPS, dedicated servers, production

OPTION 3: Systemd (Full OS Integration)
─────────────────────────────────────────
1. sudo cp glovia-backend.service /etc/systemd/system/
2. sudo systemctl enable glovia-backend
3. sudo systemctl start glovia-backend
4. Done! ✅

Time required: 5 minutes
Best for: Linux servers with systemd
